# Sahara Bakers — Install (Windows)

## Install karne ka tareeqa

1. **Sahara-Bakers-Setup-1.0.0.exe** download karein (release link se).
2. File par **double-click** karein. Agar Windows kahe "Windows protected
   your PC", to **More info** → **Run anyway** par click karein (app abhi
   signed nahi hai — ye normal hai).
3. Installer mein folder chunein (default theek hai) aur **Install** par
   click karein. Desktop aur Start Menu par **"Sahara Bakers"** shortcut
   ban jayega.
4. App kholein — **PIN screen** aayega. **Rahmanullah** chunein aur PIN
   **3333** dalein, phir **Login Karein**.
5. Pehle kaam ke tor par **Logins > Change PIN** se apna PIN badal lein
   (3333 default hai — kisi ko na batayein).
6. **Settings** mein version **1.0.0** nazar aana chahiye, aur **Items**
   mein **44 items** (28 Raw Materials + 16 Finished Goods) hone chahiye.

## App kholna (rozana)

- **Start Menu** kholein (keyboard par Windows key dabayein), **"Sahara
  Bakers"** likhein, app par click karein.
- Taskbar par pin karne ke liye: app khula ho to taskbar icon par
  **right-click → Pin to taskbar**.
- **Desktop par jo Setup (.exe) file hai, use delete kar dein** — dobara
  us par click karne se app phir se install hone lagega. App hamesha
  Start Menu ya taskbar se kholein.

## Data kahan save hota hai

Data is laptop par save hota hai:
`C:\Users\<aapka-naam>\AppData\Roaming\com.sahara.bakers\sahara-bakers-data.json`
Backups usi folder ke `backups` folder mein hain (aakhri 7 rakhe jate hain).

**Data kabhi khud delete na karein.** Agar app khaali khule ya data na
mile, to login screen par upar **⋮ menu → "Backup se Data Wapas Layein"**
dabayein — login kiye baghair data wapas aa jayega.

## Agar kuch ghalat ho

- **PIN bhool gaye / lock ho gaya:** 5 ghalat PIN ke baad login 15 minute
  ke liye lock ho jata hai — 15 minute intezar karein, phir dobara
  koshish karein. App band kar ke kholne se lock reset nahi hota.
- **Printer:** bill print karne ke liye pehle **Settings > Printer** mein
  apna thermal printer chunein.
- **Naya version:** jab naya installer mile, purana version uninstall
  karne ki zaroorat nahi — naya installer upar se install kar dein. Data
  mehfooz rehta hai (uninstall par bhi data delete nahi hota).
